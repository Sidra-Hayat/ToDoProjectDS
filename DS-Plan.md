# Data Structure Planning Table – To-Do List Manager

| Operation                     | Data Structure Used | Reason for Choosing DS                                                                 |
|-------------------------------|-------------------|---------------------------------------------------------------------------------------|
| Add New Task                  | Singly Linked List | Fast insertion at end, dynamic size, no need for contiguous memory                     |
| Delete a Task                 | Singly Linked List | Allows easy removal by adjusting pointers                                             |
| Mark Task as Completed        | Singly Linked List | Fast traversal to find target task                                                    |
| Search Task by Title          | Singly Linked List | Simple sequential search since list is not too large                                   |
| Display All Tasks             | Singly Linked List | Easy linear traversal to print items in order                                         |
| Edit Task Details             | Singly Linked List | Access node → modify fields → no shifting required                                     |
